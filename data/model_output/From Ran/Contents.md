# Contents

Ran uploaded data from 4 runs:

piControl
    The standard pre-industrial control

piControl.400 
    Uses a pre-industrial boundary condition with 400 ppm CO2

eoi400
    This is the full mid-Pliocene run from PlioMIP2

eo400.new
    Pliocene topography, geography, and CO2 (400 ppm). Preindustrial vegetation and ice sheet.


The data in each file is monthly, and covers the last 100 years of the simulations.
