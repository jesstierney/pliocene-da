# Contents

Natalie uploaded data from 3 runs. Each subfolder holds output from one of the runs.

PreInd
    This is a pre-industrial control run

PlioB17
    This is an early Pliocene run. It includes biogeochemistry and carbon isotopes.

Plio
    This is a late Pliocene run.

Each run includes a "cam" folder and a "pop" folder. The "cam" folder holds data fields from the atmospheric component of the model, and "pop" holds data from the ocean component.
Each folder holds a number of data files, each data file holds climatologies for multiple climate data fields. All climatologies are calculated using the final 100 years of the model run.
Both folders include monthly climatologies (labeled as 1-12). The "cam" folders also include seasonal climatologies (ANN, DJF, MAM, JJA, SON) and zonal-average climatologies.
